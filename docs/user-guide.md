# 📖 Guide Utilisateur - Royal Tennis Club de Fès

## 🎯 Introduction

Bienvenue dans l'application du **Royal Tennis Club de Fès** ! Cette application moderne vous permet de gérer facilement vos réservations, participer aux événements du club et accéder à tous les services premium de notre établissement.

### 🌟 Qui peut utiliser cette application ?

- **👥 Adhérents** : Membres du club avec accès aux réservations et événements
- **👨‍💼 Personnel** : Employés du club avec accès à la gestion
- **🔑 Administrateurs** : Accès complet à toutes les fonctionnalités
- **🌐 Visiteurs** : Consultation des informations publiques du club

## 📅 Système de Réservation

### 🎾 Réserver un Court

#### **Étape 1 : Accéder aux Réservations**
1. **Menu** → **Réservation**
2. **Ou** depuis l'accueil → **"Réserver maintenant"**

#### **Étape 2 : Choisir l'Activité**
- **🎾 Tennis** : Courts de tennis standard
- **🏸 Badminton** : Courts de badminton
- **🏐 Volleyball** : Terrains de volleyball
- **⚽ Football** : Terrains de football
- **🏊‍♂️ Piscine** : Accès à la piscine
- **💪 Fitness** : Salle de sport

#### **Étape 3 : Sélectionner la Date**
- **📅 Calendrier interactif** pour choisir votre date
- **🟢 Vert** : Disponible
- **🔴 Rouge** : Complet
- **🟡 Jaune** : Partiellement disponible

#### **Étape 4 : Choisir le Créneau**
- **🌅 Matin** : 6h00 - 12h00
- **☀️ Après-midi** : 12h00 - 18h00
- **🌙 Soirée** : 18h00 - 22h00

#### **Étape 5 : Sélectionner l'Installation**
- **Court 1, 2, 3...** selon la disponibilité
- **Caractéristiques** affichées pour chaque court
- **Tarifs** indiqués en temps réel

#### **Étape 6 : Confirmation et Paiement**
- **Récapitulatif** de votre réservation
- **Choix du mode de paiement** :
  - 💳 Carte bancaire (Stripe)
  - 💰 Paiement sur place
  - 🎫 Crédit club (si disponible)
- **Confirmation immédiate** par email et SMS

### 📋 Gérer vos Réservations

#### **Consulter l'Historique**
- **Menu** → **Historique des réservations**
- **Filtres disponibles** :
  - 📅 Par date
  - 🎾 Par activité
  - ✅ Par statut (confirmée, annulée, terminée)

#### **Modifier une Réservation**
- **Possible jusqu'à 24h avant** le créneau
- **Cliquer sur la réservation** → **"Modifier"**
- **Changer** la date, l'heure ou l'installation
- **Différence de prix** calculée automatiquement

#### **Annuler une Réservation**
- **Possible jusqu'à 24h avant** le créneau
- **Remboursement automatique** selon les conditions
- **Notification** de confirmation d'annulation

### ❓ Questions Fréquentes (FAQ)

#### **🔐 Connexion et Compte**

**Q : J'ai oublié mon mot de passe, que faire ?**
R : Cliquez sur "Mot de passe oublié" sur la page de connexion et suivez les instructions reçues par email.

**Q : Comment changer mon email ?**
R : Allez dans Profil → Paramètres → Informations personnelles → Modifier l'email.

**Q : Mon compte est bloqué, pourquoi ?**
R : Contactez le support. Les causes peuvent être : tentatives de connexion multiples, non-paiement, violation des règles du club.

#### **📅 Réservations**

**Q : Puis-je réserver pour quelqu'un d'autre ?**
R : Oui, si vous êtes adhérent, vous pouvez réserver pour un invité en précisant ses informations.

**Q : Combien de temps à l'avance puis-je réserver ?**
R : Les réservations sont ouvertes 30 jours à l'avance pour les adhérents, 7 jours pour les non-membres.

**Q : Que se passe-t-il si j'arrive en retard ?**
R : Votre créneau reste réservé, mais le temps perdu ne sera pas récupéré. Au-delà de 15 minutes, le court peut être libéré.

#### **💰 Paiements**

**Q : Mes paiements sont-ils sécurisés ?**
R : Oui, nous utilisons Stripe, une plateforme de paiement certifiée PCI DSS avec chiffrement bancaire.

**Q : Puis-je payer en plusieurs fois ?**
R : Pour les abonnements annuels uniquement, possibilité de paiement en 3 ou 12 fois sans frais.

**Q : Comment obtenir une facture ?**
R : Les factures sont automatiquement envoyées par email et disponibles dans votre espace personnel.

#### **🎉 Événements**

**Q : Comment être informé des nouveaux événements ?**
R : Activez les notifications dans vos paramètres ou abonnez-vous à notre newsletter.

**Q : Puis-je annuler ma participation à un événement ?**
R : Oui, selon les conditions spécifiques à chaque événement (généralement 48h avant).
