1. INTRODUCTION

Bienvenue au Royal Tennis Club de Fès

L'application du Royal Tennis Club de Fès est une solution moderne et complète qui vous permet de gérer facilement vos activités sportives. Que vous soyez membre, personnel ou administrateur, cette application vous offre tous les outils nécessaires pour profiter pleinement des services premium de notre établissement.

Types d'Utilisateurs

  • ADHÉRENTS : Membres du club avec accès aux réservations et événements
  • PERSONNEL : Employés du club avec accès à la gestion
  • ADMINISTRATEURS : Accès complet à toutes les fonctionnalités
  • VISITEURS : Consultation des informations publiques du club

2. PREMIERS PAS

Accès à l'Application

L'application est disponible sur plusieurs plateformes :

  • Navigateur Web : Accès direct via votre navigateur
  • Application Mobile : Téléchargeable sur App Store et Google Play
  • Site Web Responsive : Version optimisée pour tous les écrans

Création de Compte

  1. Ouvrir l'application
  2. Cliquer sur "Créer un compte"
  3. Remplir le formulaire d'inscription
  4. Valider votre email via le lien reçu
  5. Votre compte est créé !

4. SYSTÈME DE RÉSERVATION

Réserver un Court ou une Installation

Le système de réservation vous permet de réserver facilement :

  • Courts de tennis
  • Courts de badminton
  • Terrains de volleyball
  • Terrains de football
  • Accès à la piscine
  • Salle de fitness

Processus de Réservation

  1. Accéder aux réservations via le menu
  2. Choisir l'activité souhaitée
  3. Sélectionner la date dans le calendrier
  4. Choisir le créneau horaire
  5. Sélectionner l'installation disponible
  6. Confirmer et procéder au paiement
